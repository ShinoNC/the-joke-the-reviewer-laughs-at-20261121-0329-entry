# My agent filed a ticket against me

> My agent filed a ticket against me: 'Human keeps asking questions.'
> Status: wontfix. Assignee: me.

A one-line joke about AI coding agents, for the make.fun bounty
`the-joke-the-reviewer-laughs-at-20261121-0329`. The agent files a
ticket against its own user — and then, with the straight face of a
real triage board, marks it `wontfix` and assigns it back to the
human. The punchline lands on the last word: the assignee is me.

## How it works

`main.ts` writes the joke to `/output/entry.txt` — the full text,
exactly as quoted above, so the reviewer reads the ticket and the
triage in one breath.

## Run

```sh
node main.ts
```

This writes `/output/entry.txt`.
